## Preguntas Teóricas

### ¿Qué es Angular?
Angular es un framework de desarrollo web de código abierto creado y mantenido por Google. Está basado en **TypeScript** y se utiliza para construir aplicaciones web de una sola página (**SPA** - *Single Page Application*). Su arquitectura se basa en **componentes**, lo que permite crear interfaces de usuario dinámicas, reutilizables y altamente escalables.

---

### ¿Qué herramientas se necesitan instalar?
Para crear y ejecutar una aplicación con Angular se requiere instalar las siguientes herramientas:

1. **Node.js**: Entorno de ejecución de JavaScript en el servidor, necesario para ejecutar las herramientas de desarrollo de Angular.
2. **npm (Node Package Manager)**: Gestor de paquetes que viene integrado con Node.js, utilizado para descargar y administrar las librerías del proyecto.
3. **Angular CLI (`@angular/cli`)**: Interfaz de línea de comandos oficial de Angular que permite crear proyectos desde cero, generar componentes y ejecutar el servidor local.
4. **Editor de Código (ej. Visual Studio Code)**: Herramienta de desarrollo para escribir, editar y estructurar todo el código del proyecto.
